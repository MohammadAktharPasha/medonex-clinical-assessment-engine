Windows Administrator Setup Playbook

Complete Windows Setup & Deployment Guide

Step-by-step instructions to configure a complete, 100% free open-source Moodle LMS instance natively on Windows (no Ubuntu, no virtual machines) for the Novant Health clinical assessment and proctoring engine.

01

1. Install Official Moodle Windows Package (1-Click Zip)

Moodle officially provides a complete all-in-one Windows installer package bundled with Apache, PHP 8.1+, and MariaDB.

  1. Download Moodle 4.3 LTS (Windows installer package) from download.moodle.org/windows/.
  2. Extract the downloaded zip file directly to C:\MoodleServer on your Windows PC.
  3. Double-click C:\MoodleServer\Start Moodle.exe. A small command prompt will open and initialize Apache and MariaDB.
  4. Open Chrome or Edge and go to http://localhost. Follow the 5-minute setup wizard to create your admin account.
02

2. Configure Safe Exam Browser (Native Moodle Core on Windows)

Safe Exam Browser has an official native Windows executable (SafeExamBrowserInstaller.exe) that locks down Windows 10/11.

  1. Candidate downloads and installs the free Windows client from safeexambrowser.org.
  2. In your Moodle site (http://localhost): Go to Site Administration > Plugins > Activity modules > Quiz > Safe Exam Browser.
  3. Ensure 'Safe Exam Browser' is enabled.
  4. In your Novant Health quiz settings: Under Safe Exam Browser, set 'Require Safe Exam Browser' to Yes, enable 'Block dual monitors', and disable 'Allow quitting of SEB'.
03

3. Install Webcam Proctoring Plugin (`quizaccess_proctoring`) on Windows

Download the free open-source plugin and place it in your local Windows Moodle directory:

# In Windows File Explorer or PowerShell:
1. Download the plugin zip from https://moodle.org/plugins/quizaccess_proctoring
2. Extract the folder into:
   C:\MoodleServer\server\moodle\mod\quiz\accessrule\proctoring
3. Open your browser at http://localhost/admin
4. Moodle will detect the plugin and automatically run the database upgrade.
04

4. Inject Client-Side Eye-Gaze Tracking (Google MediaPipe WebAssembly)

Because Google MediaPipe runs inside the candidate's browser via WebAssembly, it requires zero GPU server bills on Windows.

1. In Moodle (http://localhost), navigate to:
   Site Administration > Appearance > Additional HTML
2. Paste the MediaPipe script into the "Within HEAD" box:
   <script src="https://cdn.jsdelivr.net/npm/@mediapipe/face_mesh"></script>
3. Click "Save changes". MediaPipe will automatically activate on all quiz attempt pages.
05

5. Install Custom Certificate (`mod_customcert`) on Windows

Extract the free plugin into your Windows directory to automate PDF dossier generation:

1. Download mod_customcert from https://moodle.org/plugins/mod_customcert
2. Extract into:
   C:\MoodleServer\server\moodle\mod\customcert
3. Visit http://localhost/admin to complete installation.
4. Add the Custom Certificate activity to your course with condition: Grade >= 80%.
